# Native Santa Tracker rewrite — in progress

The target is a faithful rewrite of the **entire original site and all 55 scenes in Rust**, with the original art and audio. **The current build does not meet that target yet.** It is not a completed 1:1 recreation.

The application runs native Rust window, rendering, input, simulation, Ogg decoding and audio mixing code. It does not launch Node.js, Chromium, a webview or the original JavaScript game engine. SVG and Lottie files remain artwork; native libraries render them. Original image, animation-data and Ogg resources are included under `static/`. JavaScript source and web runtime files are excluded.

## Current coverage

- Village: original four background layers, exported sprite geometry/keyframes, original fonts/logo, Play and Family Guide positions, eleven scrolling sections, native playback of their Lottie files, activity cards, a navigation grid, and snow/cloud simulation.
- Shared controls: original toolbar SVG paths, audio control, home/pause/restart controls, a takeoff countdown targeting December 24 at 10:00 UTC, and a score/time badge.
- Runner: Rust physics, seeded random generation, entity spawning, platforms, collisions, scoring, time boosts, magnet attraction, timers, pause and restart. Five scenarios are compared against snapshots generated by executing the original simulation.
- Elf Jetpack: original elf/item/cloud artwork, animated flames and sparks, sprite frames, sway/rotation, sky transitions and the finish goal. Native movement, collisions, pickups, clock bonuses, hazards, levels and spawning follow the original classes. Three seeded scenarios are checked against the original simulation.
- Santa Selfie: original SVG scene and tool artwork; the original 645-point beard, Verlet constraints, shaving, dragging, regrowth, eight paint colors, four decorations and cleaning. Native hair compositing uses the original Bézier shape. Eye tracking/blinks, facial expressions, tool animations, breathing and the barber pole are animated. Eight tool/physics steps are checked against the original classes. The original beard encoding can be saved and restored.
- Audio: original Ogg files decoded by Rust; a Rust stereo mixer supports resampling, looping, pause/mute, scheduled starts, fades and stopping individual sources. Jetpack/Selfie actions include their multiple-source starts and tool loop stops. Full process scheduling, bus effects, group behavior and musical transitions are **not** ported yet.

Most scenes still do not have native gameplay implementations. The four available scenes still have visual/interaction differences and have not passed full visual and behavioral parity. An unavailable activity reports that it is unavailable instead of silently opening another game. Maps/live tracking, videos, translations, accessibility, gamepad support, all remaining games and complete shared overlays still require work. Passing the current tests is not evidence of whole-site parity.

## Build and run

```sh
./rust/build.sh
./rust/run.sh
./rust/run.sh --scene runner
./rust/run.sh --scene jetpack
./rust/run.sh --scene santaselfie
```

Building requires Rust, a C/C++ compiler, and libclang with its builtin headers. `build.sh` handles header discovery on Linux installations that have libclang but no clang driver. Set `CARGO=/path/to/cargo` to select a toolchain. On this machine the isolated development toolchain is in `/tmp/santa-cargo` and `/tmp/santa-rustup`:

```sh
RUSTUP_HOME=/tmp/santa-rustup CARGO_HOME=/tmp/santa-cargo \
CARGO=/tmp/santa-cargo/bin/cargo ./rust/build.sh --offline
```

The executable is `rust/target/release/santa-tracker`. Runtime requirements on Linux are an OpenGL-capable desktop and SDL2 for audio. It uses original resources in `../static`; `--assets /path/to/static` overrides that location. The bundled fonts are compiled into the executable. Use `--help` for deterministic screenshot options. `--mute` avoids opening an audio device during render checks.

Runner controls: Space/Up jumps, Down slides. Jetpack: arrow keys/WASD, or hold and drag the mouse. Santa Selfie: select a tool in the tray, then hold/drag on Santa; release the growth spray to regrow hair. The reset button restores the beard. Share saves `santa-selfie.png` and `santa-selfie.beard` in the working directory. This native file export differs from the original site's URL sharing/photocard flow. Restore with `--scene santaselfie --beard-file santa-selfie.beard`.

P pauses, R restarts/resets, M toggles audio, and Escape returns to the village. Village supports mouse wheel/drag scrolling, activity cards and the toolbar menu. For live capture, pass `--screenshot /tmp/scene.png` and press F12; `--frames` captures a frozen deterministic frame after `--advance`.

## Verification

```sh
cargo test --manifest-path rust/Cargo.toml
```

The committed JSON reference snapshots were generated against the original Google implementation during development. The JavaScript reference runners remain in the separate local reference checkout and are deliberately excluded from this Rust-only repository. Rust tests consume their saved results without executing JavaScript.

Original browser captures go into `rust/target/`, with measured layout data in `data/*layout-reference.json` and Selfie expression measurements in `data/selfie-expression-reference.json`. Native screenshots can be produced using:

```sh
rust/target/release/santa-tracker --mute --frames 2 --screenshot /tmp/village.png
rust/target/release/santa-tracker --mute --scroll 1122 --frames 2 --screenshot /tmp/movies.png
rust/target/release/santa-tracker --scene jetpack --mute --seed test1234 --advance 3 --frames 2 --screenshot /tmp/jetpack.png
rust/target/release/santa-tracker --scene santaselfie --mute --seed test1234 --advance .5 --frames 2 --screenshot /tmp/selfie.png
```
