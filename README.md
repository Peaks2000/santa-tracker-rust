The reason rust is in its own folder is because I was working with the java script with the rust folder inside it but only uploaded the rust files so thats why it is that way, sorry for how messy it is!

It currently includes the village, Runner, Elf Jetpack and Santa Selfie, using the original artwork and audio with native game logic. **It is not yet a complete 1:1 port.** See the [Rust coverage, controls and build instructions](rust/README.md).
