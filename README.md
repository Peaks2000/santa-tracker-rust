# Santa Tracker Rust rewrite (in progress)

The native Rust application is in [`rust/`](rust/README.md). It currently includes the village, Runner, Elf Jetpack and Santa Selfie, using the original artwork and audio with native game logic. **It is not yet a complete 1:1 port.** See the [Rust coverage, controls and build instructions](rust/README.md).

```sh
./rust/build.sh
./rust/run.sh --scene jetpack
./rust/run.sh --scene santaselfie
```
